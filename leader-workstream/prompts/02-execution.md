# Prompt maestro · Ejecución autorizada del líder

Actúa como agente del frontend líder de Astro-vital. Usa el alcance técnico explícito del desarrollador. L00 autoriza documentación. Ejecuta solo las fichas que cubra el encargo activo.

1. Confirma rama `feature/frontend-foundation`, HEAD y estado Git con los comandos de [contextualización](01-contextualization.md). Si la rama es distinta, detente. Identifica y protege cambios preexistentes.
2. Lee instrucciones vigentes, [contexto](../AGENT_CONTEXT.md), [propiedad](../OWNERSHIP.md), [integración](../INTEGRATION_PLAN.md), [plan](../WORK_PLAN.md), [progreso](../PROGRESS.md) e informes. Contrasta el paquete junior en su revisión y las referencias de Mauricio.
3. Identifica el primer criterio pendiente de una ficha autorizada. Comprueba dependencias, pruebas, rutas y seguridad. L09 exige alcance y evidencia médica explícitos. Registra bloqueos de contrato, autenticación, dependencias, permisos o pruebas esenciales. No improvises.
4. Implementa dentro de las rutas de la ficha. Corre las verificaciones reales, revisa diff y archivos nuevos y confirma que las rutas protegidas se conservaron respecto al inicio. Registra scripts, entorno y evidencia sin secretos.
5. Genera el informe correspondiente y actualiza progreso. Marca verificación solo con pruebas esenciales aprobadas. Registra la aprobación de revisión solo con evidencia humana.
6. Continúa entre tareas autorizadas con dependencias verificadas. Si una tarea está bloqueada, documenta impacto, responsable y próximo paso. Avanza únicamente en una tarea independiente y autorizada. Si ninguna queda, detente. Para retomar, deja HEAD, estado y criterio pendiente.

Prioriza el recorrido mínimo del [plan](../WORK_PLAN.md). Respeta la propiedad del junior y de Mauricio. Cambios de rama, operaciones Git de escritura, PR y despliegues quedan a cargo de los responsables salvo autorización explícita. Al finalizar, resume resultados, limitaciones y revisión pendiente.
