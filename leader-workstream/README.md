# Plan del frontend líder

[![NASA Space Apps Challenge](https://img.shields.io/badge/NASA_Space_Apps-Challenge_2026-blue.svg)](https://www.spaceappschallenge.org/)
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](../LICENSE)

Astro-vital presenta telemetría de astronautas en una PWA de escritorio, adaptable y accesible. El líder construye la aplicación, coordina con Mauricio el acceso a datos y monta los componentes que entrega el junior.

1. Empieza con el [prompt de contextualización](prompts/01-contextualization.md), de solo lectura, en `feature/frontend-foundation`.
2. Lee [contexto](AGENT_CONTEXT.md), [plan](WORK_PLAN.md), [propiedad](OWNERSHIP.md), [integración](INTEGRATION_PLAN.md) y [progreso](PROGRESS.md).
3. Cuando se autorice la implementación, activa el [prompt de ejecución](prompts/02-execution.md). Sigue las fichas y registra evidencia usando [la guía de informes](reports/README.md).
4. Entrega el diff y los informes para revisión humana. La integración de ramas y la apertura del PR corresponden a los desarrolladores responsables.

L00 entrega documentación. El primer resultado técnico futuro es una aplicación React que renderiza. El primer resultado integrado es una muestra que viaja por el backend y se identifica en la interfaz. Las dependencias de esa integración se pueden resolver en paralelo con la base, dentro del alcance autorizado.
