# Instrucciones para frontend

1. Aplica [las instrucciones raíz](../AGENTS.md). Lee [guía técnica](docs/README.md), [integración](../docs/INTEGRATION_GUIDELINES.md) y tu ficha de rol. Confirma el requisito y las rutas concretas de la asignación. Ante un rol ambiguo o cambios transversales, coordina con el líder.
2. Trabaja solo en rutas autorizadas. La etapa documental carece de autorización para inicializar React, instalar dependencias o implementar funcionalidades. El stack adoptado para una etapa posterior es React, Vite, TypeScript y Material UI.
3. Verifica la revisión de API y los ejemplos con el líder. Registra discrepancias y dependencias en el lugar indicado por la [guía de integración](../docs/INTEGRATION_GUIDELINES.md). Mantén credenciales privadas fuera de variables `VITE_*`, bundle, fixtures y logs. Identifica la procedencia simulada.
4. Comprueba según el encargo escritorio y pantallas pequeñas, teclado, foco, carga, vacío, error, desconexión, frescura y calidad. Mantén las decisiones clínicas dentro de la [política médica](../docs/MEDICAL_CONTENT_POLICY.md).
5. Antes de entregar, revisa diff y archivos nuevos contra las rutas autorizadas. Reporta resultados reales, revisión de API si aplica, limitaciones y decisiones que requieren al líder o a Mauricio.
