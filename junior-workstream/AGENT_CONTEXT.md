# Contexto operativo del agente junior

Lee [contexto](../docs/PROJECT_CONTEXT.md), [arquitectura](../docs/ARCHITECTURE.md), [alcance](../docs/MVP_SCOPE.md), [decisiones](../docs/DECISIONS.md), [integración](../docs/INTEGRATION_GUIDELINES.md), [política médica](../docs/MEDICAL_CONTENT_POLICY.md), [rol junior](../docs/roles/frontend-junior.md), [rol líder](../docs/roles/frontend-lead.md), [reglas del frontend](../frontend/AGENTS.md) y [guía técnica](../frontend/docs/README.md).

El reto de Space Apps motiva una interfaz que permita conocer qué se midió y cuándo, incluso con enlaces intermitentes. Sensores o simulación producen datos. Mauricio mantiene la API Flask y persistencia. El líder coordina el contrato y adapta el JSON a modelos de interfaz. El junior recibe esos modelos mediante props y devuelve vistas y eventos de interacción para integrar. Se distinguen API inaccesible, nodo offline, dato obsoleto y sensor averiado. Un estado general reportado no certifica salud. Un acuse confirma reconocimiento, sin implicar resolución clínica.

React, Vite, TypeScript, Material UI y la orientación PWA desktop-first están adoptados. El líder controla base, tema, navegación, estado, adaptadores y PWA. Aquí se espera UI accesible para escritorio y pantallas pequeñas. En la copia auditada, `frontend/` tiene documentación y placeholders. `docs/` es referencia del equipo y `Backend/` es de solo lectura. Consulta la [API de Mauricio](../Backend/docs/API.md) cuando sea necesario. Las props son modelos de presentación. Tipos locales y fixtures de UI no establecen contratos REST.

J01 entrega primitivas visuales, J02 la composición de tripulación, J03 mediciones e histórico, J04 la presentación y acciones visuales de alertas, J05 evidencia de calidad e integración. La prioridad clínica, condiciones de alerta, cuestionarios, orientación, acceso al backend y estrategia offline requieren decisiones de sus responsables. Mantén fuera de la UI procedimientos sin revisión, diagnósticos, reglas clínicas inventadas y secretos. Usa datos ficticios mínimos con procedencia visible y evita incluir datos médicos personales en reportes o capturas.
